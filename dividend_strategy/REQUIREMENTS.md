# 股息率定投信号系统 - 需求文档

## 📌 核心目标

建立一个自动化系统，每天扫描A股全市场，找出同时满足以下两个核心条件的股票，并通过飞书推送信号：

1. **TTM股息率 ≥ 5%**（过去12个月的分红收益率）
2. **收盘价低于120日均线**（表示当前价格处于相对低位）

---

## 🎯 筛选规则

### 基础门槛（必须同时满足）

- 股息率（TTM）≥ 5%
- 收盘价 < MA120（120日均线）

### 过滤掉以下股票

| 过滤项 | 规则 | 说明 |
|--------|------|------|
| ST股票 | 名称包含 ST、*ST | 风险警示股 |
| 退市整理期 | 价格无效 | 通过价格是否有效判断 |
| 停牌股票 | 成交额 = 0 | 无交易 |
| 新股 | 上市不足1年 | 需要足够历史数据 |
| 市值过小 | 总市值 < 50亿 | 流动性风险 |
| 流动性差 | 日成交额 < 1000万 | 难以买卖 |
| 财务风险 | 连续亏损 | 可选，需额外数据 |
| 高质押率 | 质押率 > 50% | 可选，需额外数据 |

---

## 📊 信号分级机制

系统采用三级信号机制，基于价格连续低于MA120的天数：

| 级别 | 条件 | 含义 | 建议 |
|------|------|------|------|
| **1级** | 当天收盘价 < MA120 | 轻度，预警关注 | 可能是短期波动 |
| **2级** | 连续3天 < MA120 | 中度，趋势确认 | 趋势开始确认 |
| **3级** | 连续5天 < MA120 | 强信号，重点关注 | 明确的价值低估信号 |

**设计思路**：
- 1级信号：可能是短期波动，保持观察
- 2级信号：趋势开始确认，可以开始关注
- 3级信号：明确的价值低估信号，重点关注

---

## 📤 推送规则

### 推送时间

- 每天早上 **9:00**（开盘前）
- 只在有信号时才推送

### 推送内容

#### 基础信息
- 股票代码、名称
- 当前价格、MA120价格
- 距离MA120的跌幅（折扣力度）
- TTM股息率

#### 扩展信息
- 连续低于MA120的天数
- 信号级别（1/2/3级）
- 近期分红历史（近3年）
- 行业分类、市值、PE、PB
- 涨跌停状态

#### 统计信息
- 今日新增信号数量
- 当前总信号数量
- 按行业分布
- 按市值分布
- 按信号级别分布

---

## ⚠️ 特殊情况处理

### 除权除息期间

- 除权除息后MA120需要重新计算
- 除权除息当日正常推送信号

### 股息率数据

- 每日重新计算TTM股息率
- 年报披露期间特别标注（可能有变化）

### 市场极端情况

- **大盘暴跌**：跌幅 > 2%时，推送时特殊标注
- **涨跌停股票**：涨跌停的股票也需要推送（会特别标注）

---

## 📈 回测验证

### 回测范围

- 过去5年的数据（2021-2026）

### 回测目标

- 验证策略的可行性
- 统计历史信号数量
- 分析信号质量
- 优化参数（如需要）

### 回测指标

| 指标 | 说明 |
|------|------|
| 信号触发次数 | 历史上产生了多少次信号 |
| 信号后续表现 | 1周/1月/3月后的涨跌幅 |
| 不同级别信号的准确率 | 各级别信号后续上涨的概率 |
| 行业分布统计 | 哪些行业更容易出现信号 |

## 🎯 系统定位

### 这个系统不是

- ❌ 自动交易系统
- ❌ 卖出建议系统
- ❌ 技术分析系统

### 这个系统是

- ✅ 定投信号提醒工具
- ✅ 价值投资辅助决策系统
- ✅ 每日市场扫描器

### 核心理念

通过 **股息率（安全边际）** + **价格低估（MA120下方）** 的双重筛选，找到值得关注的定投标的。

## 📁 技术架构

### 模块划分

| 模块 | 文件 | 功能 |
|------|------|------|
| 股息率计算 | `dividend_calculator.py` | 计算TTM股息率 |
| MA120筛选 | `ma120_filter.py` | 筛选低于MA120的股票 |
| 过滤器 | `stock_filter.py` | 过滤ST/停牌/新股等 |
| 信号管理 | `signal_manager.py` | 信号分级和状态追踪 |
| 飞书推送 | `feishu_pusher.py` | 推送消息到飞书 |
| 定时任务 | `scheduler.py` | 每日扫描调度 |
| 回测系统 | `backtest.py` | 历史数据回测 |
| 配置文件 | `config.py` | 参数配置 |

### 数据来源

| 数据类型 | 来源 | 说明 |
|----------|------|------|
| 股票列表 | InStock API | 东方财富数据 |
| 历史K线 | InStock API | 用于计算MA120 |
| 分红数据 | InStock API | 用于计算股息率 |

## 📝 使用说明

### 安装依赖

```bash
pip install -r requirements.txt
```

### 配置

编辑 `config.py`：

```python
# 飞书 Webhook
FEISHU_WEBHOOK_URL = "https://open.feishu.cn/open-apis/bot/v2/hook/xxx"

# 股息率阈值
DIVIDEND_YIELD_THRESHOLD = 5.0

# MA周期
MA_PERIOD = 120
```

### 运行

```bash
# 执行一次扫描
python main.py --scan

# 启动定时任务
python main.py --schedule

# 执行回测
python main.py --backtest --sample 50
```
